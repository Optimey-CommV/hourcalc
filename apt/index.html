Optimey APT repository

Packages from Optimey for Debian 13 and Ubuntu 26.04 LTS, amd64.

Debian 13 (trixie)

sudo wget -O /etc/apt/sources.list.d/optimey.sources https://apt.optimey.be/debian13.sources
sudo apt update
sudo apt install hourcalc

Ubuntu 26.04 LTS (resolute)

sudo wget -O /etc/apt/sources.list.d/optimey.sources https://apt.optimey.be/ubuntu26.04.sources
sudo apt update
sudo apt install hourcalc

The .sources file holds the address of this repository and its public key; apt trusts that key for this repository only. Updates then arrive with the normal system updates. To remove the repository, delete /etc/apt/sources.list.d/optimey.sources.
